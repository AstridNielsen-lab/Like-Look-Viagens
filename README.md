# Like Look Viagens - Roteiro Exclusivo Turquia

## Sobre o Projeto
Este projeto apresenta um roteiro exclusivo para explorar Istambul, Turquia, com uma imersão de 7 dias na cultura, história e arquitetura locais.

## Recursos Incluídos
- Hospedagem em hotel 5 estrelas no centro histórico
- Café da manhã diário e 4 refeições especiais
- Transporte privativo para deslocamentos
- Seguro viagem e assistência 24h
- Visitas guiadas a locais emblemáticos, como a Basílica de Santa Sofia e o Cruzeiro pelo Bósforo
